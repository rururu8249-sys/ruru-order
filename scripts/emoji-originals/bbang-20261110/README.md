# 2026-11-10 빵빵이 움직이는 이모티콘 24개

사장님이 제공한 67초 화면 녹화(2026-11-10 오후 11.22.14.mov)에서 각 동작을 직접 잘라낸 등록용 GIF다. 외부 사이트 원본 파일은 다운로드하지 않았다. 마우스 포인터와 재생 전후 확대/축소 구간을 제외하고, 공통 영역으로 잘라 프레임 간 크기·위치를 유지했다. 둘레에서 연결된 회색 배경을 투명하게 바꾸고 흰 테두리를 넣어 검은 채팅 배경에서도 보이게 했다.

모두 256×256px, 무한 반복 GIF, 1MB 이하(35,816~238,311바이트)다. 화면 녹화 해상도에서 Lanczos 방식으로 크기를 맞췄으며 원본에 없는 세부 묘사나 동작을 새로 생성하지 않았다. 반복되는 동일 프레임은 재생 시간을 유지하며 합쳤다. 제공 영상의 동작 구간을 사용하므로 판매 원본 전체 동작 길이와는 다를 수 있다.

manifest.json은 이름·ID·공개 주소·연관어 394개·프레임 수·재생 시간·영상 구간·파일 SHA-256을 기록한다. 기존 49개 뒤에 이 24개를 추가해 총73개. 기존 목록·권한·구매 금액 조건은 그대로다. GIF 업로드 지원 코드는 7f0505d에 이미 배포되었다.

복구 시 관리자 이모티콘 창에서 같은 이름의 「그림 바꾸기」로 해당 GIF를 올리면 기존 ID와 대화 표식을 유지할 수 있다. 자동 등록 스크립트가 아닌 등록본 보관 폴더다.

운영 Storage product-images의 허용 MIME 목록은 기존 image/jpeg·image/png·image/webp에 image/gif만 추가했다. 기존 public=true, 저장소 크기 제한5MB와 versioning 상태는 보존했고, 이모티콘 전용 API는 기존대로1MB·256px을 검증한다.
