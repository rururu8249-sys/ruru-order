# 2026-11-10 표정 이모티콘 16개

사장님이 제공한 4×4 그림을 원본 표정·동작·글씨를 참고해 AI로 선명하게 보정한 후, 투명 배경·흰 스티커 테두리를 적용하고 각각 분리했다. 등록용 PNG는 긴 쪽 256px, 1MB 이하이며 원본 표정의 세부 선은 AI 보정으로 차이가 있을 수 있다.

`manifest.json`은 등록 순서, 고유 ID, 이름, 공개 주소, 연관어 291개, 그림 크기·바이트·SHA-256을 기록한다. 기존 33개 뒤에 16개를 추가하며 접근 규칙·구매 금액 조건·기존 그림과 단어 설정은 유지한다. 앱 코드 수정 없이 기존 keywords 설정과 추천/채팅 변환을 사용한다.

복구할 때는 관리자 이모티콘 창에서 해당 이름의 「그림 바꾸기」로 같은 파일을 올리면 기존 ID를 유지할 수 있다. 신규 재등록 시 동일 이름과 ID가 이미 있는지 먼저 확인한다. 이 폴더는 등록본 보관용이며 자동 업로드 스크립트가 아니다.
