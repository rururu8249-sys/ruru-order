# 📄 엑셀 대량등록 사용법 (혼자서도 되는 버전)

관리자페이지 → 📦 상품 관리 → 오른쪽 위 「📄 엑셀 대량등록」

## 순서 (5단계)
1. **파일 선택** — 거래처 재고 엑셀(.xlsx / .xlsm)을 올린다. 형식이 달라도 됨.
   - 옛날 .xls 파일이면: 엑셀에서 열어 「다른 이름으로 저장 → .xlsx」 한 번 하고 올리기.
2. **🔍 자동 대조 박스 확인** (미리보기 맨 위)
   - 초록 "다른 부분 없음" → 그대로 3번으로.
   - 빨강 "다른 부분이 있어요" → 빨간 줄만 확인하면 됨. 전체를 볼 필요 없음.
     - 「엑셀 합계 X개 ≠ 읽은 재고 Y개」 → 그 상품만 엑셀과 비교
     - 「E13 칸의 숫자 7 — 어느 상품에도 안 들어감」 → 엑셀에서 E13 칸을 봐서
       색상/상품명이 빈 줄이면 채우고 다시 올리기
3. **인식이 이상하면** 위쪽 드롭다운 조정 → 즉시 다시 읽힘
   - 상품이 아예 안 잡히면: 제목줄 / 구조(한 줄=한 상품, 여러 줄=한 상품, 한 줄=한 옵션) 바꿔보기
   - 이름·가격이 엉뚱한 칸이면: 상품명/가격/색상 칸 드롭다운으로 지정
   - 사이즈가 빠졌으면: 「사이즈 칸 N개」 눌러서 칸 직접 선택
   - 꼬였으면 「자동인식 다시」
4. **일괄 설정** — 배지(MD픽, 해외배송 등), 일반/업체발송, 진열/숨김, 카테고리, 가격 조정
5. **등록** — 「문제없는 것만」 누르면 경고 있는 줄은 자동 제외됨. [N개 등록하기] 클릭.
   - 주의: [등록] 누르기 전에는 DB에 아무것도 저장되지 않는다.

## 안전 수칙
- 확신 없으면 「숨김(나중에 진열)」으로 등록 → 상품관리에서 확인 후 진열
- 사진 없는 상품은 등록 후 상품 수정에서 사진만 추가하면 됨 (사진 실패해도 상품은 등록됨)
- 사진 1장 5MB 초과는 사진만 빠짐
- 잘못 등록했으면: 상품 관리 → 해당 상품 삭제 (주문 안 붙은 신규 상품은 삭제해도 무해)

## 이 기능이 건드리지 않는 것
- 주문 / 재고차감 / 입금확인 / 정산 / 배송 로직 일절 무접촉
- 등록은 기존 상품등록과 똑같은 경로(products insert)만 사용
