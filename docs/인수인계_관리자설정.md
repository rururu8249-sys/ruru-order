# 인수인계 — 관리자 계정·외부 연동 설정 (개발자용)

관리자 화면에는 이 내용을 노출하지 않습니다(사장님/인수자가 직접 실행할 수 없는 절차이므로). 사이트를 넘길 때 이 문서를 함께 넘기세요.

## 1. 관리자 로그인 아이디·비밀번호
- 로그인 기준은 **Vercel 환경변수**입니다. DB에는 관리자 계정이 없습니다.
  - `RURU_ADMIN_ID` — 관리자 아이디
  - `RURU_ADMIN_PASSWORD` — 관리자 비밀번호
  - `ADMIN_SESSION_SECRET` — 로그인 세션 서명키 (바꾸면 모든 관리자 로그인이 풀림)
- 변경 절차: Vercel 프로젝트 → Settings → Environment Variables → 값 수정 → **Production 재배포** → 새 아이디·비밀번호로 로그인.
- 코드 위치: `lib/admin-auth.ts`, `app/api/admin-login/route.ts`, `middleware.ts`(보호 경로: `/admin-live`, `/api/admin-live`, `/api/admin-v2`, `/api/bankda`).

## 2. 뱅크다(입금 자동확인)
- 크론: `vercel.json`의 `/api/bankda/sync-and-auto-match`(1분). 내부 호출 토큰은 `middleware.ts`의 `INTERNAL_CRON_API_PATHS` / `CRON_SECRET` 참고.
- 계정·키: Vercel 환경변수 (`BANKDA_*`). 값은 이 문서에 적지 않습니다.
- 안전가드 스크립트: `npm run guard:bankda`, `npm run guard:bankda-cron` — 배포 전 통과 필수.

## 3. 텔레그램 알림
- 관리자 화면 설정 › 텔레그램에서 봇 토큰만 넣고 「연결 찾기」로 chat id 자동 검색. 값은 `settings` 테이블에 저장(`telegram_*` 키).
- 봇 만들기: 텔레그램에서 @BotFather → `/newbot` → 토큰 발급. 알림을 받을 사람은 그 봇에게 아무 말이나 한 번 보내야 chat id가 잡힙니다.

## 4. 유튜브 라이브 채팅 알림(봇 계정)
- OAuth 클라이언트: Vercel 환경변수 `YOUTUBE_*`. 연결은 관리자 화면 설정 › 유튜브 알림 「유튜브 연결」.

## 5. DB 표가 없을 때 뜨는 안내
- 접속 기록: `supabase/visitor_visits_history.sql`
- 정산 추가 입력: `supabase/sql/settlement_manual_entries.sql`
- 관리자 화면에는 "개발자에게 알려주세요"라고만 뜹니다. 실행은 Supabase SQL Editor에서.

## 6. 삭제된 것 (2026-09-07)
- 1·2세대 관리자 `/admin`, `/admin-v2` 페이지와 컴포넌트, 유튜브 SEO 도구(커밋 `b75f35d`에서 복구 가능), 테스트 페이지 2개, 무궁화 이벤트 페이지. `app/api/admin-v2/*`와 `lib/admin-v2/*`는 현행 관리자가 쓰므로 그대로입니다.
