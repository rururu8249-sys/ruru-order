# 가위바위보 관리자 흐름 수정

사용자 확정 요구: 설정 저장과 모집 시작 분리, 진행/설정 중복 제거, 포인트 쉼표, 자동/수동 설명, 폰 화면 버튼 잘림 해소. 기존 진행·지급 엔진은 유지한다. 기존 반복 질문 중단 및 배포까지 진행 승인에 따라 추가 승인 대기 없이 실행한다.

- 설정 탭: 제목/인원/선물/포인트/모집시간/선택시간/루루 자동·수동. 하단 저장만 표시. 저장 후 설정 창을 닫고 방송 화면으로 복귀.
- 진행 탭 제거. 방송 위젯에 저장한 설정 요약 + 참가자 모집 시작. 연습 시작은 보조 버튼. 모집 중 위젯에서 마감하고 게임 시작. 시간은 설정에서 분/초로만 변경. 당첨자 탭 유지.
- 시작 전 설정은 서버의 관리자 전용 단일 설정으로 저장하고 모든 관리자에 동기화. 저장은 게임방·이벤트·보상을 생성하지 않음. 오래된 버전 저장/시작은 거부.
- 최초 저장 전 설정 화면부터 열기. 운영 중 설정은 기존 라운드/선물 변경 제한 유지.
- 카카오 팝업이 열리지 않는 브라우저도 동작하도록 게임 확인은 같은 창 이동, 복귀 후 관리자 창 복원.
- 헤더·탭·설정 저장 하단은 고정, 본문만 스크롤. 320/360/390/768/PC 및 짧은 화면 검증.

검증: UI 저장→방송 복귀→시작, 쉼표/모드 설명, 설정 DB 무부작용/버전 충돌/접근 제어, 기존 게임/보상 회귀, 빌드/운영 배포 및 실제 메뉴 확인.
