# 물건챙기기 작업 묶음·추가챙김 설계

## 목표

관리자가 오늘·어제 등 여러 방송을 하나의 물건챙기기 작업 범위로 묶고, 미결제였다가 나중에 결제된 주문과 이미 챙긴 뒤 상품 내용이 바뀐 주문을 놓치지 않게 한다. 화면에서 보고 있는 작업 대상과 엑셀 출력 대상은 항상 같아야 한다.

## 확정 운영 규칙

- 주문목록의 기존 단일 방송 필터는 유지한다. 다중 방송 선택은 물건챙기기 창 안에서만 제공한다.
- 작업 범위는 실제 `broadcast_id` 여러 개로 조회한다. 화면에 이미 적재된 최근 주문만 다시 거르는 방식은 사용하지 않는다.
- 빠른 범위 선택으로 `오늘`, `오늘+어제`, `선택 해제`를 제공한다.
- 결제 필터는 `전체 결제완료`, `오늘 결제`, `뒤늦게 결제`를 제공한다. `뒤늦게 결제`는 주문일보다 나중 KST 날짜에 결제가 확인된 주문이다.
- 기본 물건챙기기 목록은 결제완료·취소 아님·챙김 제외 아님인 주문을 대상으로 한다.
- 챙기기 전에 상품명·색상·사이즈·수량을 수정한 주문은 별도 예외로 만들지 않는다.
- 챙김 완료 후 상품명·색상·사이즈·수량이 바뀌면 데이터베이스가 해당 행의 `picked_at`을 자동 해제하고 재챙김 정보를 남긴다. 금액만 바뀐 경우는 재챙김하지 않는다.
- 재챙김 정보는 첫 번째 챙김 후 변경 직전 내용을 보존하고, 다시 챙긴 뒤 또 변경되면 새 직전 내용을 저장한다.
- 물건챙기기 창은 `전체 챙김`과 `추가 챙김` 두 탭을 제공한다. 추가 챙김은 뒤늦게 결제된 미챙김 주문과 변경 후 재챙김 주문을 보여준다.
- 추가 챙김 항목은 일반 전체 챙김에도 포함되지만, 일괄 완료로 닫을 수 없다. 상품별 확인 버튼으로만 완료한다.
- 엑셀은 현재 선택한 방송·결제일·검색·챙김 상태 범위를 그대로 사용한다.
- 엑셀 첫 시트 `물건챙기기`에는 전체 대상과 `일반/결제 후 챙김/변경 후 재챙김` 구분을 표시한다.
- 엑셀 둘째 시트 `추가챙김`에는 예외 대상의 주문일시, 결제/변경일시, 방송, 고객, 변경 전, 현재 내용을 표시한다. 둘째 시트는 수량 작업표가 아니라 교차 확인표다.
- 기존 주문·입금·정산·배송·재고 금액 계산은 변경하지 않는다.

## 화면 구조

물건챙기기 상단에 `작업할 방송` 다중선택 패널을 둔다. 선택된 방송 수와 주문 건수·상품 수량을 요약하고, 적용 중인 방송은 칩으로 표시한다. 방송 범위를 바꾸는 동안에는 기존 목록을 유지하고, 조회가 성공한 뒤 한 번에 교체한다.

두 탭 아래에는 기존 상품별/고객별 보기, 결제 범위, 챙김 상태, 정렬, 검색 기능을 유지한다. 결제일 필터를 추가하며, `추가 챙김` 탭에서는 예외 사유 배지와 변경 전→현재 내용을 카드에 표시한다.

## 데이터 및 안전성

- `orders`에 재챙김 요청시각, 재챙김 전 스냅샷, 재챙김 확인시각을 저장한다.
- 물리 상품 필드 변경 감지는 데이터베이스 `BEFORE UPDATE` 트리거에서 수행해 일반 수정과 재고연동 RPC 양쪽에 동일하게 적용한다.
- `picked_at`이 새로 기록되면 열려 있는 재챙김 요청의 확인시각도 함께 기록한다.
- 선택 방송 조회 API는 관리자 인증 후 방송 ID를 검증하고, 방송 ID 직접 매칭과 방송 시간대의 과거 호환 주문을 합쳐 중복 제거한다.
- 최대 선택 방송 수는 31개다. 빈 선택은 기존 창에 전달된 현재 범위를 유지한다.
- 데이터 조회 실패 시 기존 목록을 비우지 않고 오류를 보여준다.

## 완료 기준

- 오늘+어제 방송을 선택하면 두 방송의 전체 주문행이 최근 500행 제한과 무관하게 조회된다.
- `오늘 결제`로 고르면 원래 주문일과 무관하게 오늘 KST 결제된 미챙김 상품만 남는다.
- 챙긴 상품을 옵션 변경하면 즉시 미챙김 및 추가챙김 대상이 되고, 다시 챙기면 예외가 닫힌다.
- 화면에 보이는 행과 첫 엑셀 시트 행이 일치하고, 추가챙김 대상은 둘째 시트에도 나타난다.
- 기존 물건챙기기 테스트, 린트, 프로덕션 빌드가 통과한다.

## 실사용 보완 확정안

초기 배포 후 실제 주문으로 확인한 결과, 임시 선택과 적용 범위가 따로 움직이는 구조와 중첩 필터가 작업자를 혼란스럽게 했다. 아래 규칙이 위의 초기 화면 설명보다 우선한다.

- 작업 탭은 `일반 챙김`, `뒤늦게 결제`, `변경 후 재챙김`, `챙김 완료` 네 개만 사용한다. 결제 범위와 챙김 상태를 다시 고르는 중첩 필터는 제거한다.
- `뒤늦게 결제`는 선택 방송과 무관하게 KST 오늘 결제된 과거 주문을 합쳐 보여준다. 카드결제 완료인데 과거 데이터에 확인시각이 없는 행은 선택 방송 안에서 `결제시각 확인`으로 안전하게 노출한다.
- 카드결제 완료 처리 시 `deposit_confirmed_at`을 함께 기록하고, 카드미결제로 되돌리면 지운다.
- 방송 체크는 즉시 적용한다. 별도 `선택 적용` 버튼과 임시 선택 상태는 두지 않는다. 기본 목록은 최근 14일이며 과거 방송은 검색으로 연다.
- `더보기`와 조회 목록 일괄 해제는 제거한다. 일반 챙김 탭에만 `현재 목록 모두 챙김 완료`를 두고, 안전 탭은 한 건씩 확인한다.
- 과거 트리거 설치 전에 챙긴 뒤 변경된 행은 변경이력으로 한 번 소급 복구한다.
- `물건챙기기 엑셀`은 현재 탭이나 검색 결과가 아니라 적용 범위의 모든 미챙김을 한 파일로 내보낸다. 시트는 `오늘 챙길 전체`, `뒤늦게 결제`, `변경 후 재챙김`으로 나눈다.
