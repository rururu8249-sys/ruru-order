# 방송 선택 시 목록 위치와 상품 표시 보존

## 사용자 요청과 확인한 근거

2026-11-20 사용자 영상에서 방송 11·12를 선택할 때 해당 행이 ON 방송 바로 아래로 이동한다. 사용자는 왼쪽 목록의 위치는 그대로 두고 오른쪽에 선택한 방송 상품만 표시하도록 명시했다.

- 기준 운영 커밋: `d9c7f425cee0f81edc6550b70a8ab54dafc11270` (PR #51).
- `139ff3bd167d1b3067c2d9b7c962cc10eca6d140` (9/25): 최근 30일 필터에서 오래된 선택 방송이 사라지지 않도록 선택 방송과 ON 방송을 상단으로 이동시켰다. 현재 `bcListView`에 그대로 남아 있다.
- `60443b325eab4e337872d11622580b110496a897` (11/06): 시작 날짜 없는 준비 방송을 기간 필터에서도 보존했다.
- `eddf1edccc581b7ff8efc5e70c9cb9502f8ae9ac` (11/08): 오른쪽 상품 체크 작업 띠의 높이를 확보한 수정이다. 왼쪽 방송 행 재정렬 제거와는 다른 변경이다.
- `55e5d3fb75c71dbf273cf2915ab286c5bcc21db8` (11/17): 선택 방송 제목·상태 구분과 방송 생명주기를 보완했으나 선택 행 상단 이동 규칙은 유지했다. 사용자가 기억하는 작업을 이 커밋이라고 단정하지 않는다.
- 실제 React 컴포넌트로 A→B(지연)→C→B 응답을 재현했다. C 선택 후 B 상품이 표시된다. `reloadBcProducts`가 현재 선택과 요청 순서를 확인하지 않는 별도 결함이다.

## 확정할 동작

1. 방송 행 선택은 강조 표시와 오른쪽 상품 조회만 바꾼다. 왼쪽 행의 순서와 표시 집합을 클릭 때문에 변경하지 않는다.
2. ON 방송의 상단 고정은 유지하고, 나머지는 서버에서 읽은 방송 순서를 유지한다. 선택한 종료 방송을 승격하지 않는다.
3. 기간·이름 필터를 사용자가 변경하면 그때 선택된 방송을 필터 예외로 보존한다. 그 필터를 유지하며 다른 행을 클릭해도 보존하던 행을 제거하지 않는다. 다음 필터 변경 때 예외를 다시 정한다. 초기 선택·새 방송·되살리기도 필터 밖 선택이 사라지지 않게 한다.
4. 날짜 없는 준비 방송의 기간 예외, 검색·기간 프리셋, 숨긴 목록과 모바일 접기 동작은 유지한다.
5. 새 방송 상품을 불러오는 동안 이전 방송 상품 행·개수·상품별 조작을 표시하지 않는다. 최신 선택 ID와 조회 순서가 모두 맞는 응답만 반영한다. 같은 방송을 다시 선택한 경우에도 오래된 요청은 무시한다.
6. 상품을 못 읽은 경우 실제 상품 없음과 구분하고 재조회할 수 있게 한다. 상품 진열 순서, 위젯 고정/자동 순환과 방송 시작·종료, 담기·빼기·복사의 저장 조건은 변경하지 않는다.

## 수정 범위와 검증

제품 파일은 `components/admin-live/AdminLiveProductManagePopup.tsx`로 한정한다. 실제 컴포넌트를 fixture 응답으로 렌더링해 클릭·필터·응답 지연을 검사한다. 운영 데이터에 테스트 쓰기를 하지 않는다. 로그인·회원·주문·금액·포인트 정책은 이번 문제 경로에 없으며 변경하지 않는다.

수정 전 실패를 확인한 테스트를 수정 후 그대로 통과시킨다. 방송 생명주기·위젯·상품 관리 관련 기존 회귀, UI guard, 타입 검사와 프로덕션 빌드를 실행한다. 다운로드 패키지는 기준 커밋과 수정 트리를 고정하여 다른 버전에 덮어쓰지 않도록 한다. 구현·로컬 검증·운영 반영은 각각 보고한다.

## 독립 검토 후 확정한 경계와 결과

- 선택을 떠났다가 같은 방송으로 돌아오는 것도 새 선택이다. 선택 revision과 상품 원본 목록의 참조까지 맞는 조회 결과만 준비 완료로 취급한다. 같은 선택의 일반 재조회와 낙관적 순서 변경은 유지한다.
- 전체 상품 조회와 방송별 연결 조회가 모두 끝나야 상품 없음이라고 판단한다. 전체 상품 조회 실패는 해당 조회를 다시 시도하고, 연결 조회 실패는 연결만 다시 시도한다. 준비 전/실패 시 고정 상품의 미등록 경고와 관련 조작도 표시하지 않는다.
- 다른 화면에서 현재 선택의 제목·날짜가 변경되어 필터 밖으로 나간 경우에는 그 데이터 갱신 때 필터 예외를 현재 선택으로 옮긴다. 그 뒤의 단순 행 클릭은 위치를 바꾸지 않는다. 이는 기존 항상 보이는 선택 정책을 유지하기 위한 구현 결정이며 실제 데이터 갱신과 클릭을 구분한다.
- 새 테스트 17개 시나리오, 관련 스크립트 18종, guard/타입/프로덕션 빌드가 통과했다. react-test-renderer deprecated와 기존 Node 모듈 형식 경고는 있었으나 오류 종료는 없었다.
- 운영 배포와 수정본의 실제 브라우저 재검증은 적용 후 진행한다. 현재 결과는 로컬 실제 컴포넌트 + fixture 검증이다.
