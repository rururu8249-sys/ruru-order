# 방 전체 반복 검사와 당일 주문 상품 문맥

사용자 확정: 방송 중·잠시 멈춤·종료 모두 현재 상품카드 또는 당일 주문 상품을 참고한다. 품번 없이 색상 감상만 반복하지 않는다. 기존 TEST 표시·실제 고객 우선·발언 간격·주문/금융 보호는 유지한다.

운영 근거: 11/21 메시지 6036–6049의 14개 연속 발언이 올리브 감상이다. 최근 director 로그 6047/6048/6049는 모두 `normal`/Gemini 3.1 Flash Lite다. 기존 관심사 검사는 focused 후보 순위에만 있었고, color/style/choice 중 하나만 분류했다. 일반 생성의 최종 검사는 계정별 색상 반복만 제한했다. 모델에 보여준 실제 주문 상품도 전송 단계에서 현재 카드 밖 상품으로 거절됐다.

변경:
- 같은 순수 주제 분석을 일반/보완 프롬프트, 후보 순위, 최종 전송 검사에서 공유한다. 색상+코디 감상은 겹치는 관심사로 본다. 기존 90분 기억·최근 두 발언의 세 번째 반복 제한을 유지한다. 실제 고객의 현재 질문 답장은 예외다. 알림은 반복 기억을 차지하지 않는다.
- 색상·외형 독립 감상에는 검증된 품번 또는 기존 한글 별칭+번호가 필요하다. 명시적 답장의 원문에 대상이 있으면 반복 호명을 요구하지 않는다. 서버가 품번을 사후 합성하지 않는다.
- 해당 방송의 한국시간 당일 실제 주문에서 상품 ID/이름만 읽고 현재 공개·연결된 카탈로그의 정확한 세부상품과 대조한다. 최대 6개를 일반/보완 생성기에 함께 전달한다. 주문자의 이름·주문량·주문 사이즈·금액은 전달하지 않는다. 자기 구매나 인기 주장 근거로 사용하지 않는다.
- 어떤 상품을 말했는지에 맞춰 색상·배송·품질 검사와 action의 상품 키를 기록한다. 주문 기반 소재는 발송 직전 당일 주문/현재 카탈로그를 재조회한다. 삭제·숨김·이름/옵션 변경 시 침묵한다.
- `분리되나요`가 개인 사이즈 질문으로 분류되는 별도 방해 원인을 재현했다. 구조/관리의 이 표현을 개인 사이즈 검사에서 구분하고 CP-1 같은 한 자리 품번을 인정한다. 실제 체형 추천의 키/몸무게 요구는 유지한다.

범위: 현재 방송에 연결된 당일 주문만 사용한다. 고정 대사·주제/상품 순환·추가 계정·실제 고객에게 시험 발송·유료 모델·새 키·DB 마이그레이션 없음. 실제 모델의 자연스러움/다양성은 배포 뒤 운영 관측 대상이며, 테스트 통과만으로 보장하지 않는다.
