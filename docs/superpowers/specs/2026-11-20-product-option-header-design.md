# 상품 옵션 시트 스크롤 깜박임 수정

## 확인된 설계와 재현

- 기준: main `c5c29f9a7f1e56c654cd809a9a88d77740f472c0`.
- 최초 설계: `ad1438085708359184143e110040860fa28f8277` — 본문 대표사진, 200px 초과 시 헤더 64px 썸네일.
- `4c52b371184ab7658b5cd1a4113c760380ef38a9` — 브랜드 선택 단계의 44px 로고와 빨간 안내 유지.
- 사용자 영상은 제목만 깜박이는 것이 아니라 안내가 있는 헤더와 사진이 있는 헤더가 반복된다.
- 운영 브라우저에서 같은 상품, 400×737에서 재현: 헤더 86.59375px / 본문 451px / scrollTop 201.5 → 헤더 77px / 본문 461px / scrollTop 192 → 원상태 반복. 본문 scrollHeight는 653px로 동일.
- 제목은 이미 한 줄 말줄임이다. 제목 길이 자체를 원인으로 단정하지 않는다.

## 선택한 수정

옵션 시트만 헤더의 관측 최대 border-box 높이를 유지한다. 초기 useLayoutEffect와 ResizeObserver로 측정하고, 열린 동안 min-height를 줄이지 않는다. 닫기·다른 상품으로 변경 시 초기화한다. 측정과 CSS 기준을 맞추기 위해 opt-in 헤더에 border-box를 명시한다.

상하 전환 기준을 따로 바꾸는 방법은 본문 움직임을 남긴다. 스크롤 좌표를 보정하는 방법은 브라우저 보정 여부와 복원 상태 관리가 복잡해진다. 높이를 유지하면 확인된 반복의 원인인 헤더 축소 → 본문 확대 → 스크롤 보정을 직접 차단한다.

## 보존 범위

200px 기준, 썸네일·확대, 안내 표시 조건, 제목 말줄임, 상품/가격/수량/재고/장바구니 처리, 소개 상품 복귀, 기존 닫기·뒤로가기 처리와 다른 시트의 기본 레이아웃을 보존한다. 데이터베이스 변경은 없다.

## 검증

실제 공유 시트를 렌더링하는 회귀 테스트에 운영에서 측정한 높이 변화를 입력한다. 실제 주문 페이지의 활성화 속성과 스크롤 핸들러도 실행한다. 높이 유지, 상하 스크롤 값 처리, 콘텐츠 증가, 재열기, 상품 변경, opt-out, 관찰자 해제, 사진 확대·닫기 전달을 검증한다. 이는 브라우저 레이아웃 경계 모형을 사용하는 컴포넌트 검증이며 실제 단말 스크롤 검증과 구분한다. 기존 관련 테스트, guard, 타입 검사, 빌드를 실행한다. 운영 배포와 실제 단말 재검증 여부는 별도로 보고한다.

## 검사 중 확인한 기존 테스트 불일치

`test-product-discount-ui.mjs`는 원래 판매가의 표시값을 숫자 219000으로 기대했다. 격리한 기준 커밋에서도 실제 '219,000'과 불일치하여 같은 24행에서 실패했다. 테스트/할인 입력 컴포넌트의 기준본과 작업본 해시도 동일했다. 원본 커밋 `37def1eba3230633800f1972b19eaa618ba4e774`와 CLAUDE.md의 10월 29일 결정은 화면에 쉼표를 표시하고 저장값은 숫자로 유지하도록 명시한다. 이 근거에 따라 기존 테스트를 화면 '219,000' 및 onChange 숫자 219000 두 가지 검증으로 바로잡았다. 할인 입력/계산의 제품 코드는 수정하지 않았다.
