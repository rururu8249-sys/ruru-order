## 무엇
- 관리자(/admin-live) 화면 색을 DESIGN-ADMIN.md §1·§7 의 새 색(연회색 바탕 #F5F5F5·흰 판·검정 #111111 글자/주버튼·회색 선 #E5E5E5·상태색 ok/warn/danger/info)으로 **토큰 값만** 바꿔 미리 본다.
- 컴포넌트 클래스는 손대지 않았다. `app/globals.css` 에 `[data-ruru-admin-ui="v2"] { --color-… }` 블록 하나로 기존 토큰(canvas·surface·ink·line·rose-*·coral-*·cardpay·상태색)을 덮어쓴다. 숫자 tabular-nums, 포커스는 키보드(:focus-visible)일 때만 검정 2px.
- 스위치 `lib/adminUiSwitch.ts`(손님 `lib/customerUiSwitch` 와 같은 방식): `?preview=a1` → localStorage `ruru_admin_preview_a1=1`(그 브라우저만), `?preview=off` → "0", 주소 없으면 저장값, 없으면 기본값 `ADMIN_PREVIEW_DEFAULTS.a1 = false`.
- `AdminLiveDashboard` 가 useEffect 로 `<html data-ruru-admin-ui="v2|v1">` 를 달고, 화면을 떠나면(언마운트) 뗀다 → 대시보드 밖에 붙는 창(portal)·토스트도 같은 색을 받는다. (처음엔 대시보드 루트 div 에 달았다가 portal 이 못 받아서 html 로 옮김.)
- 다크 모드: `.dark` 는 안쪽 대시보드 div 에 붙어 있어 다크 토글이 우선(1차는 라이트만).
