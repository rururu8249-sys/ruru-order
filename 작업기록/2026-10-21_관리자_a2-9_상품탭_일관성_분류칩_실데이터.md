# 2026-10-21 관리자 리뉴얼 a2-9 — 상품 3탭 머리줄 통일·정렬 이름·분류 칩을 실제 데이터로

사장님 지적: 상품 메뉴 세 탭(방송 상품·쇼핑몰 상품·전체 상품)이 순서·모양이 제각각, 정렬 「이름 ㄱㄴㄷ순」 설명, 전체 상품 분류 칩이 신발·의류·잡화뿐인 이유.

## 왜 칩이 그것뿐이었나(사실)
코드에 `BASE_CATEGORIES = ["전체","신발","의류","잡화"]` 고정값. DB 실측(products.product_note.category, 읽기 SELECT): 의류 454 · 화장품 72 · 분류 없음 69 · 신발 50 · 잡화 50 · 향수 42 · 캔들/차량용 3 · 음식 2 · 루이비통/프라다/몽클레어/구찌 1씩. → 화장품 72개·향수 42개는 칩으로 못 고르고 있었음.

## 바꾼 것(AdminLiveProductManagePopup 표시만 · 저장/담기/재고/정렬 계산 무변경)
- 분류 칩 = 실제 등록된 분류에서 생성, 개수 많은 순, 개수 표시(「의류 454」). 2개 이상인 분류만 칩(1개짜리 브랜드명은 오입력이라 「전체」에서 검색). 분류 없는 상품이 있으면 「분류 없음 69」 칩. 「재고임박」 칩 유지.
- 세 탭 머리줄 같은 모양: [제목 N개(13/700 검정)] … [정렬 select 36px] [선택 복사(방송만, 보조)] [+ 담기(검정, 맨 오른쪽)]. 전체 상품도 「전체 상품 N개」 제목 줄 추가(정렬은 거기로). 검색칸 세 탭 모두 36px·14px·제목 바로 아래.
- 정렬 이름: 「이름 ㄱㄴㄷ순」 → 「이름순」, 전체 상품 「기본순」 → 「저장된 순서」(선택지 순서 최신 등록순·저장된 순서·재고 적은순, 기본값 최신 등록순 그대로).
